03 · The pipeline

Message first, then the look, with a check between every stage

One folder per stage. Each stage has a short contract saying what it reads, what it makes and who checks it. Nothing moves on until that check passes.

  1. Script

    What it says, as captions, before any picture exists.check: I skim the captions

  2. Storyboard

    One beat per picture change, holds named, still no code.check: I read the beats

  3. Build

    An AI session writes the page on a shared engine and shared rules.check: the build's own tests

  4. Review

    Stills of every beat, draw-time per frame, a hidden-tab test, the console, then a second model's verdict.check: I watch it start to finish

  5. Publish

    One commit, pushed only on my word, then the live URL must answer.check: HTTP 200 on the live page

Each review writes what it learned back into the shared rules, so the next story starts from a better engine. One example from the lens rebuild is on the next page.
