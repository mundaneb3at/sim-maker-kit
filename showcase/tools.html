How this was made 05 / 07 · The toolset

05 · The toolset

Each tool has one job. The checks between them are mine.

Bigger models where judgment matters, smaller ones for scripted and mechanical work. That keeps quality where it counts and cost down everywhere else.

In use

Agent

Claude Code

The AI that writes the code, runs the checks and drives the browser, one session per stage.

Models

Claude Opus · Fable · Sonnet · Haiku

Opus designs and makes judgment calls. Fable gives the independent verdict on a finished piece. Sonnet runs scripted builds. Haiku does mechanical checks, such as the link check on this site.

Animation

Canvas2D + GSAP timeline

One timeline owns the clock: a label per beat, holds, scrubbing, and a pause when the tab is hidden.

Diagrams

diagram-design

A Claude plugin with a fixed design system; both pipeline diagrams were made with it.

Review

Chrome, automated

Stills of every beat, draw time per frame, console errors, and the phone-width screenshots of these pages.

Publish

GitHub Pages

One commit per piece; a page counts as shipped only when its live URL answers.

Installed for the video, not used yet

Voice

Piper

A local AI voice, so narration costs nothing per take.

Timing

faster-whisper

Turns the narration into word-level timestamps that captions and cuts follow.

Render

ffmpeg

Frames plus voice into one vertical video.

Planned

Video generation

Kling AI, free tier

Two or three short generated clips for the video, labelled as a first run.
